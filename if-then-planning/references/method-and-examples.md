# 方法依据与例子

If–Then Planning 的学术名称是 Implementation Intentions（实施意图）。Gollwitzer 与 Sheeran 区分目标意图（想实现什么）与实施意图（在特定情境采取什么行动）。原理是把可识别线索与有助于目标的反应连接起来。以下来源于创建时已核实的作者原文，存档页面已停止维护，适合查定义而非最新研究结论：
https://cancercontrol.cancer.gov/brp/research/constructs/implementation-intentions

不要把研究中的平均效果当成个人成功概率，不声称必然形成习惯、不宣称提高某个倍数。目标澄清、完成信号和复查是 Skill 的工程化配套设计，不冒充原理论标准步骤。

示例（须根据用户现实替换）：
- 用户已经确认周六早餐后可用 20 分钟：如果周六吃完早餐坐到书桌前，那么打开练习文档完成第一道题并记录答案。第一题是启动动作；20 分钟练习或阶段目标另定验收。
- 用户已经确认容易被陌生词卡住：如果阅读时遇到不懂的术语，那么标记该词并先读完当前段落，再集中查询。
- 用户只说“有空就复盘”：先问哪个现实事件后能留出时间，不擅自改成每天早上六点。

障碍计划不一定需要“降级”：也可以改变位置、准备资源或应对干扰。用户不认可目标时，先重新选择或取消承诺。


## 跨次修订示例

用户已选“午饭后坐回工位，讲解一个概念两分钟”，本周五个工作日中两天外出；其余三次都开始了，但三次都卡在同一推导。不要报告“执行率只有60%”并新增提醒。可用机会三次都启动，当前证据指向内容理解或练习反馈，保留午饭线索；建议只针对卡点做一次查证后复述，仍需用户认可。观察能否解释该推导即可，不加多个指标。

如果旧卡写早餐后阅读，新卡写早餐后复述，而用户明确已用新卡替换旧卡，只修订新卡；旧卡注明失效需要对应的写入授权。用户没有说明替换关系、且两张卡争用同一时段时，先澄清当前有效计划，不静默叠加。

可复制的轻量接续格式（仅需持久化时用，已有格式优先）：

> 当前计划：如果……，那么……；复查……。
> 最近结果：实际发生了……（用户自述或记录来源）。
> 本次决定：保留……；将……改为……，因为……。下次只看……。

“本次决定”未获认可时写“建议”，不能伪装成已经承诺。暂停或完成时改记状态即可，不强制填写后续行动。
